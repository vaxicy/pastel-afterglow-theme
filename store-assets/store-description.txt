NAME
Pastel Afterglow Theme

SUMMARY
A soft pastel Chrome theme blending muted lavender, blush pink, and creamy peach for a gentle afterglow.

DESCRIPTION
Pastel Afterglow Theme brings the soft colors of evening to Chrome. A muted lavender frame pairs with a creamy peach toolbar and active tab, while a pale blush new tab page keeps your browsing space light and calm. Deep plum text and icons keep the interface clear and easy to read.

Inspired by sugar-soft clouds and the last glow of sunset, this minimal theme uses solid colors throughout. No wallpaper, no extra scripts, and no permissions required.

FEATURES
- Muted lavender window frame.
- Creamy peach toolbar and active tab.
- Pale blush new tab page with deep plum text.
- Simple cloud and sunset theme icon.
- Solid colors, minimal design, and no permissions required.
